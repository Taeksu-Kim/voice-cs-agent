# customer-service-agent

음성 제약(STT 오류·지연·끼어들기) 아래에서 상담 업무를 끝까지 수행하는 한국어 상담 에이전트와, 그것을 측정하고 개선하는 평가 파이프라인. 개인 학습 프로젝트이며 **개발 중**이다.

> **비공식 프로젝트 안내**
> - 이 저장소는 **토스(비바리퍼블리카 및 계열사)와 무관한 개인 학습 프로젝트**다. 토스의 공식 서비스·제품이 아니며, 토스의 승인이나 후원을 받지 않았다.
> - 업무 절차는 공개된 토스 고객센터 FAQ와 토스쇼핑 판매자 문서를 참고해 만든 **모의 상담**이다. 고객·카드·주문·송금 정보와 도구(정지·분실신고·링크 발송 등)는 모두 가짜이며 실제 시스템에 연결되지 않는다.
> - **FAQ·문서 원문은 저장소에 포함하지 않는다** (`data/` 제외). 저장소에는 원문에서 확인한 절차·번호 같은 사실과, 직접 쓴 시나리오·지시문만 있다.
> - 토스의 로고·디자인 자산은 쓰지 않는다. 상표는 각 소유자의 것이다.

## 무엇을 하나

| 업무 | 방향 | 에이전트가 하는 일 |
|---|---|---|
| S1 배송·주문 문의 | 인바운드 | 주문 조회 → 상태·지연 안내, 처리할 수 없는 일은 고객센터·상담원 연결 |
| S4 착오송금 | 인바운드 | 송금 조회 → 사유 분기(실수·거래대금·타인요구) → 접수 링크 또는 사기 의심 시 상담원 연결 |
| S5 카드 분실 | 인바운드 | 카드 조회 → 앱 본인 인증 → 고객 확인 후 일시정지·분실신고 실행 |
| O1 셀러 페널티 사전 안내 | 아웃바운드 | 담당자 확인 → 페널티 현황 안내 → 반발 시 소명 가이드 발송 |

## 구조

```
고객 발화 ─▶ 라우터 ─▶ 업무 워커 (업무별 지시문·허용 도구·YAML 단계 프로토콜)
                          │  검색(하이브리드: 형태소 BM25 + 임베딩, 리랭커) ─ 근거 문서
                          │  LLM(JSON 출력: say·tool·intent) ─ say는 스트리밍으로 바로 음성화
                          ▼
                       실행 게이트 ─ 인증·고객 확인·결과 안내 전 종료 차단 등 (코드가 결정)
                          ▼
                       도구(모의) ─▶ 결과 → 다음 스텝
```

- **결정적 워크플로 + LLM (C')**: 진행 순서와 실행 허락은 코드(프로토콜·게이트)가 정하고, LLM은 고객 말 이해와 응답 생성을 맡는다. 고른 이유는 `docs/05_에이전트_구조_설명.md`.
- **지시문으로 안 막히는 실패는 코드로 막는다**: 확인 없는 실행, 근거 없는 전화번호, 발송 전후 같은 말 반복 등. 각 결정의 근거 실행은 코드 주석과 프로토콜 머리 주석에 남겼다.
- **음성**: VAD → STT(Whisper turbo) → 에이전트 → 문장 단위 TTS(Supertonic). 끼어들기 시 응답 취소.

## 평가

- **시나리오**: 개발 세트 20개(`scenarios/`) + 보류 세트 8개(`scenarios_heldout/`). 업무와 고객 행동(정상·말 바꿈·인증 실패·남의 주문 등)의 조합.
- **고객 시뮬레이터**(LLM)와 에이전트를 대화시키고 채점한다.
  - 규칙 채점: 필수·금지 도구, 마일스톤 순서, 처리 결과, 음성 길이·형식, 반복
  - LLM Judge: 필수 내용 전달, 금지 언행, 목표 해결, 실패 후 완료 발언, 턴별 근거 여부, 시뮬레이터 이탈
- **Judge 신뢰도** (`docs/07_실험_Judge_신뢰도.md`): 76통화·501항목 재판정 일관성, 참조 라벨 대비 일치도 측정.
  - 참조 라벨은 사람이 아니라 Claude Opus 5.5가 붙였다.
  - 무작위 40건 기준 일치 95%, κ 0.72. 판정기 실패 표본이 적어 방향 확인용이다.

```bash
python scripts/run_eval.py --agent C --repeat 2            # 전체
python scripts/run_eval.py --agent C --only s5_ o1_h6      # 일부 시나리오
python scripts/monitor.py runs/<시각> --follow             # 실행 중 지표
python scripts/rejudge.py runs/<A> runs/<B> --k 3          # 저장된 통화 재판정
```

## 실행 환경

로컬 GPU 1장(RTX 4090 24GB)과 로컬 모델만 쓴다. 외부 LLM API는 쓰지 않는다.

| 구성 | 사용 |
|---|---|
| LLM | Qwen3.8-27B-INT4 (vLLM) |
| 임베딩·리랭커 | Qwen3-Embedding-0.6B, Qwen3-Reranker-0.6B |
| 벡터 DB | Milvus Lite |
| 형태소 분석 | kiwipiepy |
| 서버·웹 | FastAPI, 바닐라 JS (통화·업무 화면·모니터) |
| 음성 | faster-whisper, Supertonic |

```bash
bash scripts/serve.sh start          # 임베딩·리랭커·LLM 서버
python scripts/collect_toss.py       # 공개 문서 수집 → data/raw/ (저장소에 올리지 않음)
python scripts/build_index.py        # 정제·청크·색인
python scripts/run_server.py         # 웹 (http://<IP>:8080)
python -m pytest -q                  # 테스트
```

`collect_toss.py`는 공개 페이지를 개인 학습용으로 받아 로컬에만 저장한다. 받은 원문은 다시 배포하지 않는다.
